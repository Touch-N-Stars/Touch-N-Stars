# Privacy Policy for Touch'N'Stars

**Last updated: August 21, 2026**

This Privacy Policy explains how data is processed when using **Touch'N'Stars**, for what purposes such processing may take place, and what rights users have under applicable data protection law.

Touch'N'Stars is designed so that its essential functions can be used without a user account, advertising, tracking, or analytics services.

## 2. Principles of Data Processing

Touch'N'Stars does not require users to create an account and does not create personal user profiles.

The application does not use its own advertising, behavioral tracking, or analytics services.

During normal operation, information required by the application is processed locally on the user's device or exchanged directly with systems and devices explicitly configured by the user.

Information is transmitted to the Touch'N'Stars team only where this is technically necessary for a function explicitly used by the user or where the user actively initiates such transmission, for example by voluntarily submitting log or diagnostic data for troubleshooting or support.

---

## 3. Locally Stored Settings

Settings configured within Touch'N'Stars may be stored locally on the user's device.

These may include, for example:

* application settings
* connection parameters
* display preferences
* device configurations
* locally generated status information

These data are generally not transmitted automatically to the Touch'N'Stars team.

Where applicable, the legal basis for such processing is Article 6(1)(b) GDPR where processing is necessary to provide functions requested by the user.

---

## 4. Location Data

Touch'N'Stars may access location information from the user's device if the user grants the corresponding operating-system permission.

Location data may be used in particular for:

* synchronizing astronomical location information with connected systems or equipment
* calculating or displaying the current section of the sky
* location-dependent functions within the Celestial Atlas or comparable astronomical views

Location information is used solely to perform the respective function.

Location data is not automatically transmitted to the Touch'N'Stars team.

Permission to access location information can be changed or withdrawn at any time through the operating-system settings of the user's device.

Where applicable, the legal basis is the user's consent pursuant to Article 6(1)(a) GDPR and the corresponding permission granted through the operating system.

---

## 5. Images, Logs, and Locally Generated Files

Touch'N'Stars may store images, log files, and other technical information locally on the user's device as part of its normal functionality.

This information may include, for example:

* application logs
* error messages
* technical status information
* astronomical images or preview images
* diagnostic information

These files are generally stored locally and are not automatically transmitted to the Touch'N'Stars team.

Where access to files, photos, or device storage is required, such access is used only to the extent technically necessary for the requested functionality.

---

## 6. Voluntary Submission of Log and Diagnostic Data

Touch'N'Stars includes functionality that allows users to voluntarily submit log files or diagnostic data to the Touch'N'Stars team, for example for troubleshooting or in connection with a support request.

Such transmission does **not occur automatically**.

Data is transmitted only when the user explicitly initiates the corresponding upload.

### 6.1 Log Content

The application and system logs submitted through this function are designed not to contain personal information such as:

* the user's name
* email address
* user account details
* contact information
* other direct personal identifiers

Touch'N'Stars does not require a user account, and uploaded log packages are not automatically associated with a known user.

Depending on the selected diagnostic options, a submission may contain technical information such as:

* Touch'N'Stars application logs
* technical diagnostic information
* application or software version information
* information about connected astronomical equipment or software components
* error messages
* system or runtime information
* in the case of PINS, selected system diagnostic information

This information is intended to contain only technical data required for troubleshooting.

If the user manually enters a problem description or other free-text information as part of the submission, the user should avoid including personal, confidential, or otherwise sensitive information.

---

### 6.2 Random Log Token

When a log or diagnostic package is submitted, Touch'N'Stars generates a **random log token**.

This token is used as the reference identifier for the submitted log package.

The token:

* is randomly generated
* is not derived from the user's identity
* does not contain the user's name, email address, or account information
* does not by itself allow the Touch'N'Stars team to identify the user

Without further information from the user, the Touch'N'Stars team cannot determine which person submitted a particular log package solely from the random log token or from the application logs themselves.

After a successful upload, the user may provide this token when requesting support.

If the user contacts the Touch'N'Stars team and voluntarily provides the corresponding log token, the support team can use the token to locate the submitted log package and associate it with that particular support request.

The association between a log package and a user therefore occurs only if the user voluntarily provides the corresponding token as part of a support request or other communication.

---

### 6.3 Technical Connection Data

Although the uploaded application and system logs themselves are designed not to contain personal information, technically necessary connection information is processed when communicating with the upload server.

This may include, in particular:

* the IP address from which the connection is established
* date and time of the request
* technical request information
* HTTP status information

Processing of such information is technically necessary to establish and secure communication over the internet.

Technical connection information is not used to create user profiles, for advertising, or for tracking Touch'N'Stars users.

---

### 6.4 Purpose of Log and Diagnostic Processing

Submitted log and diagnostic data is used exclusively for:

* troubleshooting technical problems
* investigating reported errors
* responding to support requests
* identifying software or hardware compatibility issues
* improving the stability and reliability of Touch'N'Stars and PINS

The random log token is used solely to locate the corresponding submitted diagnostic package.

Where a user provides the token as part of a support request, the log package may be associated with that support request for the purpose of investigating the reported problem.

Where applicable, the legal basis is Article 6(1)(b) GDPR where processing is necessary to provide support requested by the user.

Where diagnostic data is voluntarily submitted independently of such a support request, processing may also be based on the user's consent pursuant to Article 6(1)(a) GDPR.

---

### 6.5 Retention and Automatic Deletion of Submitted Logs

Submitted log and diagnostic packages are stored only temporarily.

They are retained for a **maximum of 14 days after submission**.

After this period, the submitted log and diagnostic data is **deleted automatically**.

This automatic deletion also takes place if the user does not contact the Touch'N'Stars team or does not provide the corresponding log token.

The random log token ceases to provide access to the submitted diagnostic package once that package has been deleted.

Users who require support should therefore provide their log token to the Touch'N'Stars team before the 14-day retention period expires.

Voluntarily submitted log and diagnostic packages are automatically deleted no later than **14 days after submission**, as described in Section 6.

## 14. Right to Lodge a Complaint

Under Article 77 GDPR, data subjects have the right to lodge a complaint with a competent data protection supervisory authority if they believe that the processing of their personal data infringes applicable data protection law.

A complaint may in particular be submitted to the supervisory authority responsible for the data subject's habitual residence, place of work, or the place of the alleged infringement.
